# 셀러메이트 AI 🤍

> 혼자 장사하는 사람을 위한 AI 직원

온라인 쇼핑몰을 혼자 운영하는 소상공인을 위한 웹앱입니다.
상품명부터 상세페이지, 인스타 홍보글, 쇼츠 대본, 마진 계산까지 한 곳에서 만들 수 있습니다.

<br>

## 실행 방법 (처음이신 분용)

컴퓨터에 **Node.js**가 설치되어 있어야 합니다. ([공식 사이트에서 설치](https://nodejs.org) · LTS 버전 권장)

터미널(명령 프롬프트)을 열고 이 폴더에서 아래를 순서대로 입력하세요.

```bash
npm install     # 처음 한 번만 (필요한 파일을 내려받습니다)
npm run dev     # 앱 실행
```

실행되면 터미널에 `http://localhost:5173` 같은 주소가 나옵니다.
그 주소를 브라우저에 붙여 넣으면 앱이 열립니다. 휴대폰 화면 크기로 봐도 잘 나옵니다.

앱을 멈추려면 터미널에서 `Ctrl + C` 를 누르세요.

<br>

## 인터넷에 올리고 싶을 때

```bash
npm run build   # dist 폴더가 만들어집니다
```

만들어진 `dist` 폴더를 [Vercel](https://vercel.com)이나 [Netlify](https://netlify.com)에
그대로 올리면 주소가 생깁니다. (둘 다 무료로 시작할 수 있습니다)

<br>

## 담긴 기능 5가지

| 기능 | 하는 일 | 입력하는 것 |
| --- | --- | --- |
| 🛒 상품명 만들기 | 검색 노출형·감성형·타겟 지목형 등 스타일별 상품명 최대 9개 | 상품명 + 특징 · 강조 장점 · 타겟 · 가격대 · 분위기 · 검색 단어 |
| 📝 상세페이지 만들기 | 첫 문구 3개 + 본문 전체 + 자주 묻는 질문 | 상품명 + 특징 · 강조 장점 · 타겟 · 가격 · 분위기 |
| 📸 인스타 홍보글 만들기 | 스토리텔링형·정보형·이벤트형 피드 글 3개 + 해시태그 | 상품명 + 특징 · 강조 장점 · 타겟 · 가격 · 분위기 |
| 🎬 쇼츠 대본 만들기 | **15초 / 30초 / 60초**를 골라 초 단위 장면·대사·자막·촬영 메모 | 상품명 + 영상 길이 · 특징 · 강조 장점 · 타겟 · 분위기 |

**분위기는 9가지**입니다 — 감성적인 · 친근한 · 신뢰감 있는 · 고급스러운 · 트렌디한 · 귀여운 ·
전문적인 · 유머러스한 · 담백한. 고르면 예문이 바로 보이고, 신뢰감·고급·전문·담백은
'합니다체', 나머지는 '해요체'로 어투까지 바뀝니다.
| 💰 판매가 / 마진 계산 | 순이익, 마진율, 손익분기 판매가, 목표 마진율별 권장가 | 판매가 · 매입가 · 배송비 · 플랫폼 수수료 · 광고비 · 기타 비용 |

어느 기능이든 **상품 이름 하나만** 넣으면 결과가 나옵니다. 나머지 칸은 모두 선택이며,
채우는 만큼 문구가 정확해집니다. 감이 안 잡히면 각 화면의 **"예시로 채워보기"** 버튼을
누르면 예시 값이 채워지고 결과까지 바로 나옵니다.

결과 화면에는 **📋 전체 복사하기**와 **🔄 다른 결과 만들기** 버튼이 맨 위에 있고,
결과 카드마다 개별 복사 버튼이 아래에 붙어 있습니다.

<br>

## MVP 범위

이번 버전에 **없는** 것들입니다. (요청에 따라 일부러 넣지 않았습니다)

- 회원가입 / 로그인
- 결제
- 데이터베이스 (새로 고치면 입력값이 사라집니다)
- 외부 AI API 호출 — 문구는 앱 안에 들어 있는 카피라이팅 규칙으로 즉석에서 만듭니다.
  그래서 **인터넷 없이도, 요금 없이도, 기다림 없이** 바로 나옵니다.
  나중에 Claude API 같은 것을 붙이려면 `src/lib/generators.js` 의 함수를 교체하면 됩니다.

<br>

## 폴더 구조

```
src/
├─ App.jsx                첫 화면(카드 5개)과 화면 이동
├─ styles.css             전체 디자인
├─ components/            여러 화면이 함께 쓰는 부품
│  ├─ ProductForm.jsx     상품 정보 입력 폼 (선택 칸 켜고 끄기 가능)
│  ├─ CopyBlock.jsx       결과 카드 + 복사 버튼
│  ├─ ResultActions.jsx   전체 복사하기 / 다른 결과 만들기 버튼
│  ├─ ChipGroup.jsx       눌러서 고르는 버튼 묶음
│  ├─ ToolHead.jsx        각 도구의 제목과 사용 순서(1-2-3)
│  └─ TipBox.jsx          "이렇게 쓰면 더 좋아요" 안내
├─ tools/                 기능 5개 화면
│  ├─ ProductNameTool.jsx
│  ├─ DetailPageTool.jsx
│  ├─ InstagramTool.jsx
│  ├─ ShortsTool.jsx
│  └─ MarginTool.jsx
└─ lib/
   ├─ generators.js       ★ 문구를 만들어내는 핵심 규칙
   ├─ tones.js            ★ 분위기 9가지 단어 사전 + 카테고리·타겟·가격대·영상 길이 선택지
   ├─ korean.js           한국어 조사 처리 (은/는, 이/가, 을/를) + 겹치는 단어 정리
   ├─ clipboard.js        복사 기능 (권한 막힌 브라우저 대비책 포함)
   ├─ formState.js        입력 폼 초기값 + "예시로 채워보기" 값
   └─ useCopyTool.js      입력 → 생성 → 결과 표시 흐름
```

문구를 내 스타일로 바꾸고 싶다면 `src/lib/tones.js` 의 단어들을 고쳐보세요.
분위기를 새로 추가하고 싶으면 그 파일의 `TONES` 배열에 한 덩어리를 복사해 넣으면 됩니다.
가장 쉽고, 결과가 바로 달라집니다.
